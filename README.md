# Blackthorn Academy — The Veiled Moon

## The correct experience

**Projector:** cinematic story only, full-screen and borderless. The default website no longer has player-app tabs or admin sidebars.

**Personal phones:** an in-world smartphone interface inspired by the original blackthorn-phones project. Separate Florine, Maxine and Sam screens with Messages, Photos, Camera, Blackthorn, Map, Notes, Calendar and Calls.

## Phone preview test

Open Blackthorn on the phone's home-screen app grid, then choose **Simulate next chapter**. This releases another set of sample messages for that phone **only**. It is a local preview, not the real mystery unlock process.

## GitHub-only scope

The GitHub Pages site is a **standalone, spoiler-safe preview**. It requires no Firebase, Railway, ntfy or other third-party service. It retains local browser progress and independent character previews. **GitHub Pages alone cannot securely synchronize confidential, role-restricted story decisions in real time across unrelated devices.** The private V18 story code remains private and has not been published to Pages. Shared real-time play would require a trusted running process or hosted backend, neither of which is enabled here.

## Runtime status and safety

GitHub Pages is still a **spoiler-safe front-end preview**, not a synchronized full game. The private V18 prototype separately includes shared state, private role links and server-authoritative pause, but the public GitHub Pages preview is not connected to that private server. The complete story, puzzles and finale still need validation.
